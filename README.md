# LearnTube AI — Full-Stack LLM-Based YouTube Learning Assistant

An AI-powered web learning platform for students. Paste educational YouTube video links to extract transcripts, generate structured Smart Notes, create interactive revision flashcards, engage in grounded RAG Q&A with an AI tutor, and perform semantic vector searches across your video library.

---

## 🚀 Key Features

1. **YouTube Transcript Extraction**
   - Direct extraction using LangChain's `YoutubeLoader` and `youtube-transcript-api`.
   - Compatible with both modern (`v1.2+`) and legacy versions of `youtube-transcript-api`.
   - Never downloads video files (saves bandwidth and disk space).
   - Cleans bracketed audio noise (`[Music]`, `[Applause]`, `(inaudible)`) and normalizes whitespace.
   - Resilient error handling for disabled captions, private videos, and invalid URLs.

2. **Smart Notes (LLM-Powered)**
   - Automatically generates structured study notes using **Groq** (`openai/gpt-oss-20b` — 100% Free & blazing fast) or **OpenAI** (`gpt-4o-mini`).
   - Smart transcript sampling ensures even 1–2 hour long lectures are summarized without token limits.
   - Strict JSON output containing:
     - **Summary**: Concise video overview.
     - **Key Points**: High-yield takeaways.
     - **Definitions**: Key terms and academic definitions.
     - **Formulas**: Mathematical and technical equations.
     - **Instructor Examples**: Case studies and analogies used in the lecture.
     - **Important Concepts**: Exam preparation checklist.
   - Zero hallucination guardrail: grounded strictly in the transcript.

3. **AI Video Chatbot (Grounded RAG)**
   - Interactive chat assistant grounded in the video transcript.
   - Employs **Retrieval-Augmented Generation (RAG)**:
     $$\text{Student Question} \rightarrow \text{Local Embedding} \rightarrow \text{ChromaDB Vector Match} \rightarrow \text{Context} \rightarrow \text{AI Answer}$$
   - Filters chunks by `video_id` so conversations remain focused on the current lecture.
   - Remembers recent conversation history for natural follow-up questions.
   - Explicitly informs students if a concept was not covered in the lecture.

4. **Interactive Flashcards**
   - Active recall revision deck generated by the LLM.
   - Interactive 3D card flip animation with keyboard shortcuts (Space to flip, &larr; / &rarr; arrow keys to navigate).
   - Progress bar and card counter.

5. **Multi-Video Course Library & Dashboard**
   - Organize videos by course/subject (e.g., *Machine Learning*, *Calculus*, *Python Programming*).
   - Global dashboard tracking total videos, completed videos, notes, flashcards, and completion percentage.
   - Filter videos by course with one click.

6. **Semantic Smart Search**
   - Search across all video transcripts using **Local ONNX MiniLM vector embeddings** and ChromaDB cosine similarity.
   - Finds matching concepts even if the exact keyword was not spoken in the video.
   - 100% Free & runs directly on your CPU without consuming API credits.

## ⚙️ Installation & Setup

### 1. Prerequisites
- Python 3.10+ installed
- Free Groq API Key (from [console.groq.com](https://console.groq.com)) or OpenAI API Key

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables
Edit your `.env` file (or copy from `.env.example`):

```env
# Flask Configuration
FLASK_APP=app.py
FLASK_ENV=development
SECRET_KEY=dev-secret-key-youtube-learning-assistant

# Free AI Provider (Groq — 100% Free & Fast)
LLM_PROVIDER=groq
GROQ_API_KEY=gsk_your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-20b

# Embeddings: 'local' (Free offline ONNX, ₹0 cost) or 'openai'
EMBEDDING_PROVIDER=local

# Storage Configuration
DATABASE_URL=sqlite:///youtube_learning.db
CHROMA_PERSIST_DIR=chroma_db
```

### 4. Run the Application

```bash
python app.py
```

Open your browser and navigate to:
```
http://localhost:5000
```

## 🔍 How It Works Under the Hood

### 1. YouTube Transcript Extraction
When you submit a YouTube URL:
1. `YouTubeService.extract_video_id()` handles URLs of any format (`watch?v=`, `youtu.be/`, `/embed/`, `/shorts/`, mobile links).
2. `TranscriptService` calls LangChain's `YoutubeLoader.from_youtube_url(url, add_video_info=True)` with fallback to `youtube_transcript_api` instance/static methods across all available caption languages.
3. Extracted transcript text is cleaned of audio cues (e.g. `[Music]`, `(applause)`) and saved to SQLite.

### 2. Smart Notes Generation
1. Cleaned transcripts are processed by `LLMService.generate_smart_notes()`.
2. For long lectures (> 20,000 characters), smart multi-segment sampling extracts introductory concepts, core definitions/formulas, and conclusion sections to respect rate limits without losing lecture context.
3. Strict system prompts enforce grounding and output structured JSON with keys: `summary`, `key_points`, `definitions`, `formulas`, `examples`, and `important_concepts`.
4. The output is parsed and stored in the `Notes` table in SQLite.

### 3. ChromaDB Vector Indexing & Persistence
1. Transcripts are chunked into 900-character segments with 120-character overlaps using `RecursiveCharacterTextSplitter`.
2. Each chunk is embedded using **Local ONNX MiniLM** (`all-MiniLM-L6-v2`) at ₹0 cost.
3. Chunks and vector embeddings are stored in a persistent local ChromaDB collection (`youtube_transcripts`) with metadata: `video_id`, `video_title`, `course_name`, `chunk_index`, and `source`.
4. Data is persisted on disk in `./chroma_db/` across application restarts.

### 4. Grounded RAG Chatbot
1. When a user asks a question on `/video/<id>/chat`, the question is embedded with the local embedding model.
2. ChromaDB retrieves the top most relevant transcript chunks filtered strictly by `video_id`.
3. The prompt is assembled with retrieved excerpts + recent conversation turns.
4. The AI tutor answers grounded strictly in the video context. If a concept was not covered in the video, it states: *"This information is not covered in this video."*

### 5. Semantic Smart Search
1. On `/search`, enter any natural language question or topic (e.g., *"Where is gradient descent explained?"*).
2. ChromaDB performs vector cosine similarity search across all indexed transcripts.
3. Matching results display the matched text, similarity score, course name, video title, and direct links to YouTube and the chat tutor.
